El residuo

Ingresa dos enteros y pulsa «Calcular residuo».

LA REGLA

a = b × q + r

a es el dividendo, b el divisor, q el cociente entero y r el residuo.

Usamos módulo euclídeo: 0 ≤ r < |b|. El residuo siempre es no negativo, incluso con entradas negativas. Por ejemplo, −10 = 3 × (−4) + 2. Esta convención puede diferir del operador % de algunos lenguajes.

Un residuo 0 indica divisibilidad exacta. Para comprobar paridad se calcula a MOD 2, independientemente del divisor elegido.
